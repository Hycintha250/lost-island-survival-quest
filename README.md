# Lost Island: Survival Quest

A complete 3D survival adventure project for Godot 4.4+

## Run
1. Open this folder in Godot 4.
2. Open `scenes/main/main.tscn` and press F6/F5.
3. Desktop controls: WASD, Shift, Space, E, Left mouse, I, C, M.
4. Touch controls appear automatically for non-mouse devices.

## Android

The project includes `export_presets.cfg` for Android. Install Android SDK + JDK, download Godot Android export templates, configure the Android SDK in Godot Editor > Editor Settings > Export > Android, then export from Project > Export.

## Features
- Procedurally assembled island, player, survival HUD, inventory, crafting, missions, enemy AI, save/load and Android controls
- Original low-poly geometry with no paid assets or network dependencies
- `user://lost_island_save.json` local save file
